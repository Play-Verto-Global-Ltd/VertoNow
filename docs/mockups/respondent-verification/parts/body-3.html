Notes

  1. 1

    Three sentences, one of which is new. It has to say what confirming buys rather than that an email is coming — "you'll get an email" is a cost with no stated benefit, and the card is asking for the address at the exact moment a respondent is deciding whether to close the tab.§5 §7

  2. 2

    The banner renders on /you only, not on the end screen. The end screen belongs to the creator's Verto and already carries the card; putting a Playverto system banner there would be the third thing competing for the same moment. Note it is a new partial rather than a reused one — the creator's equivalent is gated on Current.user and a respondent is not one, which is a small cost the estimate carries rather than a blocker.§4

  3. 3

    The resend is the part that needs care. Rate-limited like the creator's (5 per 10 minutes) and reachable only from inside a signed-in session, so it can only ever mail the address of the account you are already in — which is what keeps it from being an enumeration oracle or a mail-bomb button. Note this is a different threat model from #join: that endpoint takes an address from an anonymous caller, this one takes none at all.§4

  4. 4

    Sequencing that matters: the Google door already stamps email_verified_at, so the moment the amber tag exists it is correct for Google respondents without any further work. The tag is not new state — it is the state the database has been carrying all along, finally drawn.§2

  5. 5

    One number worth having before this ships, and it is a one-line query rather than a project: Player.where(email_verified_at: nil).where.not(password_digest: nil).count — every respondent already in this position. They are the backfill question in §8, and whether that is 20 people or 2,000 changes whether a one-off mail-out is worth writing.§8

Explicitly out of scope: gating anything on confirmation. No blocked claim, no hidden results, no locked wallet. The creator gate for User is on publishing because an unproven creator can collect other people's birth dates under a borrowed address; an unproven respondent can only fail to hear back, so the consequence and the remedy are the same thing and a gate would add nothing but harm to conversion.
